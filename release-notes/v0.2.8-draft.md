# Wizardry 8 한국어 패치 v0.2.8 — 저널 수정

대상: Wizardry 8 1.24 / Fan Patch 1.28 build 6735

## 수정 내용

- 저널에서 종족/고유명사 `Mook`가 `묵`으로 번역되던 항목을 `Mook`로 통일합니다.
- 저널 소스의 Mook 관련 16개 항목을 점검하고 한국어 번역에서 `묵` 표기가 남지 않도록 정리했습니다.
- 저널 화면의 일부 흰색/비활성 문장에서 나타나는 글자 크기·기준선 불균형, 앞쪽 깨진 글리프, 초록색 픽셀 잔상 문제를 릴리스 차단 이슈로 분류했습니다.

## 릴리스 전 검증

- 1.24와 1.28에서 동일한 저널 장면 비교
- 검은색 일반 항목과 흰색/비활성 항목의 글꼴 크기, baseline, 문자 advance 확인
- 문자열 시작 제어코드 및 색상 상태가 한글 2바이트 처리에 섞이지 않는지 확인
- Mook 관련 저널 항목 전체에서 `묵` 0건 확인
- `FACT.DBS` 저널 필드 외 변경 0건 확인
- 양 패키지 ZIP CRC 및 SHA-256 재검증

> 이 문서는 배포 바이너리 재빌드와 인게임 검증이 끝나기 전까지 초안입니다.
