# Wizardry 8 한국어 패치 v0.2.8 — 저널 수정

대상: Wizardry 8 1.24 / Fan Patch 1.28 build 6735

## 수정 내용

- 저널에서 종족/고유명사 `Mook`가 `묵`으로 번역되던 16개 저널 슬롯을 `Mook`로 통일했습니다.
- v0.2.7에서 갈무리9 교체 대상에서 빠져 있던 `Data/JOURNAL/journal_font.sti`를 수정했습니다.
- 저널 한글 1,196개 글리프를 갈무리9 기반 픽셀 형태로 교체하고 라틴 문자 기준선에 맞게 재배치했습니다.
- 비한글 2,103개 글리프는 기존 v0.2.7의 ETRLE 압축 데이터를 그대로 유지했습니다.

## 정적 검증

- `FACT.DBS` 변경 바이트는 Mook 관련 16개 저널 필드 범위 안에만 존재함을 확인했습니다.
- Mook 관련 저널 문자열에서 `묵` 잔존 0건을 확인했습니다.
- `journal_font.sti`의 한글 1,196개 프레임만 교체되고 비한글 2,103개 프레임의 압축 데이터는 동일함을 확인했습니다.
- STI 3,299개 프레임 전체 ETRLE 재해독 검사에서 행 너비 및 스트림 경계 오류 0건입니다.
- 1.24 / 1.28의 수정된 `FACT.DBS` 및 `journal_font.sti`는 바이트 단위로 동일합니다.
- 두 ZIP 모두 CRC 검사 통과 및 내부 `SHA256SUMS.txt` 검증을 완료했습니다.
