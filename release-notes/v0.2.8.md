# Wizardry 8 한국어 패치 v0.2.8 — 저널 표기/글꼴 수정

대상: Wizardry 8 1.24 / Fan Patch 1.28 build 6735

## 변경 내용

- 저널에서 종족/고유명사 `Mook`가 `묵`으로 번역되던 16개 슬롯을 `Mook`로 통일했습니다.
- `FACT.DBS`에서 Mook 관련 저널 필드만 변경했고, 저널 필드 외 데이터 변경은 0건입니다.
- v0.2.7에서 갈무리9 교체 대상에서 빠져 있던 `Data/JOURNAL/journal_font.sti`를 수정했습니다.
- 저널 한글 1,196개 글리프를 갈무리9 기반 픽셀 형태로 교체하고 라틴 문자 기준선에 맞춰 재배치했습니다.
- 비한글 2,103개 글리프의 ETRLE 압축 데이터는 v0.2.7과 동일하게 유지했습니다.

## 검증

- Mook 관련 저널 항목 전체에서 `묵` 잔존 0건
- `FACT.DBS` 저널 필드 외 변경 0건
- `journal_font.sti` 3,299개 프레임 전체 ETRLE 재해독 통과
- 1.24 / 1.28의 수정 `FACT.DBS`, `journal_font.sti` 바이트 단위 동일 확인
- 양 패키지 ZIP CRC 검증 통과
- SHA-256 검증 완료
